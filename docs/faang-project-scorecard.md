# FAANG Project Scorecard

Use this scorecard weekly. Score each category 1-5.

## A) Product and business value

- Problem definition clarity
- Target users and workflows are explicit
- Success metrics are measurable

## B) Architecture and design

- Components and data flow are clear
- Tradeoff decisions are documented
- Failure and fallback paths are covered

## C) Code quality and correctness

- Test coverage depth
- Error handling quality
- Input validation and edge-case handling

## D) AI/ML quality

- Output quality evaluation method
- Retrieval quality and grounding metrics
- Hallucination and safety checks

## E) Security and governance

- Access control and least privilege
- Policy controls and audit trail quality
- Data handling and compliance documentation

## F) Reliability and scalability

- SLOs defined and tracked
- Performance baselines measured
- Capacity and scaling approach documented

## G) Deployment and operations

- Reproducible runbooks
- Rollout and rollback strategy
- Incident response notes

## H) Presentation and interview readiness

- 2-minute and 10-minute narrative quality
- Demo reliability and clarity
- Honest constraints and ownership articulation

## Scoring rubric

- 1: Minimal or missing
- 2: Early draft
- 3: Good foundation
- 4: Strong and defensible
- 5: Exceptional and interviewer-impressive

## Target

- Minimum total: 30/40
- Competitive target: 34+/40
- 10/10 bar: 37+/40 with no category below 4
