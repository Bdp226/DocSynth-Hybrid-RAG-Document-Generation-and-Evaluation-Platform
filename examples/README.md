# Demo Evidence

Real output from this system, committed so it can be inspected without
installing or running anything.

Everything here is regenerated by a single command, so it cannot drift from the
code:

```powershell
python scripts/generate_demo_assets.py
```

| File | What it is |
|---|---|
| [sample-input-raw.txt](sample-input-raw.txt) | Raw deck-extracted source: slide numbers, action items, meeting chatter, unstructured measurements |
| [sample-output-synthesised.md](sample-output-synthesised.md) | The publication-ready document produced from it |
| [sample-technical-reference.pdf](sample-technical-reference.pdf) | Rendered PDF artifact |
| [sample-technical-reference.docx](sample-technical-reference.docx) | Rendered DOCX artifact |
| [manifest.json](manifest.json) | Structure and content-integrity analysis of the output |

---

## Before → after

**Input (raw deck extraction):**

```
Slide 12: Ingestion overview. Priya said she'd follow up on the connector list.
Action item on slide 13. The platform accepts slide decks, PDFs and workspace documents.
Slide 14: it normalises them into chunked text with slide-accurate figure extraction.
...
Baseline config processed 18 documents per minute at 4.2 seconds median latency.
Tuned config processed 42 documents per minute at 1.8 seconds median latency.
Cached config processed 61 documents per minute at 1.1 seconds median latency.
```

**Output (rendered document):**

```markdown
## Retrieval

Chunks are ranked by a hybrid scorer that fuses BM25 lexical matching with
embedding similarity. Lexical scoring preserves precision on exact identifiers
such as model names and ticket references; embedding similarity recovers
paraphrased intent.

## Measured Throughput

| Configuration | Throughput (docs/min) | Median latency (s) |
| --- | --- | --- |
| Baseline | 18 | 4.2 |
| Tuned | 42 | 1.8 |
| Cached | 61 | 1.1 |
```

What changed, and why it matters:

| Transformation | Evidence |
|---|---|
| Slide references removed | `leak_counts.slide_reference = 0` |
| Meeting chatter removed | `leak_counts.meeting_chatter = 0` |
| Roster/name references removed | `leak_counts.roster_role = 0` |
| Loose measurements became a structured table | `tables_rendered = 1`, `table_rows = 3` |
| Output passes integrity checks | `content_integrity_pass = true` |

These are not claims in a README — they are fields in
[manifest.json](manifest.json), produced by the same `analyze_document` function
that gates production runs.
